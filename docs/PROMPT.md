# 개발 프롬프트 (Development Prompt)

> 이 문서는 테트리스 게임을 만들기 **전에** 스스로 작성한 개발 프롬프트입니다.
> 실제 구현은 아래 명세를 그대로 따라 진행했습니다.

---

## 역할

너는 Python과 pygame에 능숙한 게임 개발자다. 유지보수가 쉽고 테스트 가능한
구조로 **현대식 가이드라인(Tetris Guideline)을 따르는 싱글 플레이어 테트리스**를 만든다.

## 목표

1. `python main.py` 한 줄로 실행되는 데스크톱 테트리스 게임.
2. 게임 규칙(로직)과 화면 출력(렌더링)을 완전히 분리한다.
   - 로직 모듈은 pygame을 import 하지 않는다 → 단위 테스트가 쉬워진다.
3. 블록·배경 이미지는 외부 파일을 다운로드하지 않고 **코드로 직접 생성**해 PNG로 저장한다.
4. 코드는 역할별 모듈로 분할하고, 각 모듈은 한 가지 책임만 가진다.

## 기술 스택

- Python 3.10+
- pygame 2.x (렌더링·입력·이미지 생성)
- pytest (로직 단위 테스트)

## 게임 규칙 명세

| 항목 | 내용 |
|---|---|
| 보드 | 가로 10칸, 세로 20칸 (위에 보이지 않는 2줄 버퍼) |
| 블록 | I, O, T, S, Z, J, L 7종, 가이드라인 색상 |
| 생성 | 7-bag 랜덤 (7개 블록을 섞어 순서대로 지급) |
| 회전 | SRS(Super Rotation System) + 벽차기(wall kick), 시계/반시계 |
| 고스트 | 하드 드롭 시 떨어질 위치를 반투명으로 표시 |
| 홀드 | 블록 1개 보관, 블록이 고정되기 전까지 1회만 사용 가능 |
| 미리보기 | 다음 블록 5개 표시 |
| 중력 | 레벨별 낙하 속도 `(0.8 - (level-1)*0.007)^(level-1)` 초/칸 |
| 락 딜레이 | 바닥에 닿은 뒤 0.5초 후 고정, 이동/회전 시 리셋(최대 15회) |
| 점수 | 1줄 100, 2줄 300, 3줄 500, 4줄(테트리스) 800 × 레벨 / 소프트드롭 1점·칸, 하드드롭 2점·칸 |
| 레벨 | 10줄마다 레벨 +1 |
| 게임오버 | 새 블록이 생성 위치에서 겹치면 종료 |

## 조작키

| 키 | 동작 |
|---|---|
| ← / → | 좌우 이동 (길게 누르면 자동 반복: DAS 170ms, ARR 50ms) |
| ↓ | 소프트 드롭 |
| Space | 하드 드롭 |
| ↑ / X | 시계 방향 회전 |
| Z / Ctrl | 반시계 방향 회전 |
| C / Shift | 홀드 |
| P / Esc | 일시정지 |
| Enter | 시작 / 재시작 |

## 이미지(에셋) 생성 명세

- `tools/generate_assets.py`가 pygame `Surface`로 그려 `assets/images/`에 PNG 저장.
- 블록 타일(30×30): 기본색 바탕 + 위/왼쪽 밝은 하이라이트 + 아래/오른쪽 어두운 그림자
  + 안쪽 사각 광택 → 입체적인 베벨(bevel) 느낌.
- `ghost.png`: 테두리만 있는 반투명 타일.
- `background.png`: 어두운 세로 그라데이션 + 은은한 격자.
- 게임 실행 시 이미지가 없으면 `assets.py`가 자동으로 생성한다.

## 품질 기준

- 로직(`tetromino`, `randomizer`, `board`, `game`)은 pygame 없이 테스트 가능해야 한다.
- 시간은 `update(dt)`로 주입한다 → 프레임레이트와 무관하게 동작하고 테스트에서 시간을 조작할 수 있다.
- 매직 넘버는 `config.py`에 모은다.
- `pytest`로 줄 삭제, 충돌, 회전/벽차기, 홀드, 점수, 게임오버를 검증한다.
